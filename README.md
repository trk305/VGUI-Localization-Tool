# Better VGUI Localization Tool
The Better VGUI Localization Tool made by trk305 is a tool that was forked from "CrackedComputerStudios" and originally made by "Dragon". The tool makes localizing VGUI text files a breeze.

Supports Goldsrc, Source, and should be Source 2 (unconfirmed)
# Supported Games
The Better VGUI Localization Tool can read an english file with not too many strings like tf_english.txt (can read it but not all of it)

According to my knowledge, the tool supports:

HL2, HL2 episodes, Portal, Portal 2, Left 4 Dead 2, CS:S, DOD:S, SOURCE SDK 2013 MP, SOURCE SDK 2013 SP, and any Goldsrc/Source mods
