# Better VGUI Localization Tool
The Better VGUI Localization Tool made by trk305 is a tool that makes localizing VGUI text files a breeze.

# Supported Games
The Better VGUI Localization Tool can read an english file with not too many strings like tf_english.txt (can read it but not all of it)

According to my knowledge, the tool supports:

HL2, HL2 episodes, Portal, Portal 2, Left 4 Dead 2, CS:S, DOD:S, SOURCE SDK 2013 MP, andSOURCE SDK 2013 SP
